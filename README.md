# Bulls and Cows

Игра «Быки и коровы» на TypeScript: чистые функции, иммутабельное состояние, TDD.

```bash
npm install
npm test        # Vitest
npm run lint    # ESLint
npm run format  # Prettier
npm run build   # tsc → dist/, затем открыть index.html через любой статический сервер
```

Архитектура и сложность — в [DESIGN.md](./DESIGN.md).
